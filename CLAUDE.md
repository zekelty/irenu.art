# irenu.art — заметки для Claude

Статический сайт на GitHub Pages (репозиторий `zekelty/irenu.art`, ветка `main`, домен irenu.art через Cloudflare DNS).
Данные — Supabase (`js/config.js`, публичный publishable key; права режет RLS).

- `index.html` + `js/app.js` — публичный сайт, **на английском**. Контент берётся из таблиц `site`, `members`, `projects`, `project_members`.
- `js/socials.js` — соцсети команды (TikTok, YouTube, X, Tumblr, TG-канал) — правятся в файле, без SQL. Иконки — `js/icons.js` (Simple Icons).
- `admin.html` + `js/admin.js` — админка, на русском. Доступ: пользователь в Supabase Auth + его почта в таблице `editors`.
- `me/` — личный раздел (PWA для iPhone), на русском: доски (`me_boards`) и тесты (`me_tests`, `me_attempts`). Каждый видит только свои записи.
- `supabase/*.sql` — миграции, пользователь запускает их руками в SQL Editor (по порядку, все идемпотентны).
- Пасхалки с числом 23 разбросаны по коду — сохраняй их.

## Как добавить тест для /me (по просьбе пользователя)

1. Создай файл `me/tests/<slug>.txt` (латиница, дефисы):
   ```
   title: Название теста
   description: Короткое описание (необязательно)
   ---
   ? Вопрос
   + правильный ответ
   - неправильный ответ
   - ещё неправильный
   ! пояснение после ответа (необязательно)
   ```
   Правильных ответов может быть несколько. Вопрос может занимать несколько строк (до первого варианта).
2. Добавь имя файла в массив `me/tests/index.json`.
3. Закоммить и запушь в `main`. Приложение `/me` само подтянет тест при открытии вкладки «Тесты»
   (GitHub Pages обновляется ~1 минуту). Изменение файла обновит тест, удаление из `index.json` — удалит его.

`git push` с этой машины иногда падает с `Connection was reset` — просто повтори несколько раз.
