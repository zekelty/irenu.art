# irenu.art

Сайт команды: кто мы, проекты, участники (у каждого своя страница). Это статика на GitHub Pages, данные лежат в Supabase.

```
index.html        — сайт (главная, #/project/<slug>, #/member/<slug>)
admin.html        — админка: вход, команда, участники, проекты, загрузка картинок
js/config.js      — ключи Supabase (их нужно вписать)
supabase/schema.sql — таблицы, права, хранилище картинок
CNAME             — домен irenu.art
```

Пока ключи в `js/config.js` пустые, сайт показывает демо-данные.

---

## 1. Supabase (≈5 минут)

1. Зайди на https://supabase.com, нажми **New project** (тариф Free). Регион выбирай ближе к вам, например Frankfurt.
2. **SQL Editor → New query**: вставь туда весь `supabase/schema.sql` и нажми **Run**.
3. **Authentication → Users → Add user → Create new user**: для себя и для каждого из команды укажи почту и пароль, включи **Auto Confirm User**.
4. Снова зайди в **SQL Editor** и выполни, подставив ваши почты:
   ```sql
   insert into public.editors (email) values
     ('you@example.com'),
     ('friend@example.com');
   ```
5. **Authentication → Sign In / Providers**: выключи **Allow new users to sign up**. Без этого кто угодно сможет зарегистрироваться. Писать в базу он всё равно не сможет, но лишние аккаунты ни к чему.
6. Открой **Project Settings → API** и скопируй **Project URL** и **anon public** key в `js/config.js`.
   Ключ anon публичный, его можно коммитить. Ключ `service_role` в репозиторий не клади никогда.

Новый человек в команде — это шаги 3 и 4 для его почты.

## 2. GitHub Pages

1. На GitHub создай новый репозиторий, например `irenu.art`, публичный.
2. Залей в него эти файлы (через GitHub Desktop или командами ниже):
   ```bash
   git init
   git add .
   git commit -m "Сайт команды"
   git branch -M main
   git remote add origin https://github.com/<твой-ник>/irenu.art.git
   git push -u origin main
   ```
3. В репозитории открой **Settings → Pages**. В **Source** выбери *Deploy from a branch*, ветку `main`, папку `/ (root)`.
4. В **Custom domain** впиши `irenu.art` (это поле само подхватится из файла CNAME) и нажми **Save**.
5. Когда DNS заработает (пункт 3), включи **Enforce HTTPS**.

## 3. Домен irenu.art (nic.ru)

Сейчас у домена NS-серверы `statuspage1/2.nic.ru`, это заглушка. Чтобы домен смотрел на GitHub, нужны DNS-записи. Есть два пути:

**А) Оставить DNS в nic.ru.** Править записи там можно только с подключённой услугой **«DNS-хостинг»** или **«DNS-премиум»**. Цену и условия смотри в личном кабинете.

**Б) Бесплатно через Cloudflare.** Добавь сайт на cloudflare.com (тариф Free). Он выдаст два NS-сервера, их нужно вписать в nic.ru: у домена нажми «Изменить» под DNS-серверами. Записи ниже тогда добавляешь в Cloudflare и ставишь им **DNS only** (серое облачко).

Какие записи нужны:

| Тип   | Имя   | Значение               |
|-------|-------|------------------------|
| A     | @     | 185.199.108.153        |
| A     | @     | 185.199.109.153        |
| A     | @     | 185.199.110.153        |
| A     | @     | 185.199.111.153        |
| CNAME | www   | `<твой-ник>.github.io.` |

У домена стоит уровень безопасности «Обязательный», поэтому смену NS nic.ru попросит подтвердить. Обновление DNS занимает от 15 минут до суток.

## Как пользоваться

- Админка: `https://irenu.art/admin.html` (внизу сайта есть ссылка «вход для команды»).
- **Команда**: название, подзаголовок, текст «Кто мы», контакты.
- **Участники**: имя, роль, аватар, текст о себе, ссылки.
- **Проекты**: обложка, описание, статус, год, теги и галочки «кто делал».
- Картинки при загрузке сжимаются до 1600px и сохраняются в Supabase Storage. На бесплатном тарифе там 1 ГБ.
- Изменения видны на сайте сразу, коммитить ничего не нужно.

Посмотреть сайт локально:
```bash
python -m http.server 8765
```
и открыть http://localhost:8765

## Тренер в /me

Толик и чат-бот работают через Supabase Edge Function `me-coach`. При подключении Tooken Club доступны Claude Opus 5.5 (по умолчанию) и GPT-6 Luna. Тренировки после подтверждения черновика сохраняются в личном журнале Supabase. График по упражнениям учитывает записи журнала и прежние тренировки из вкладки «Журнал» Google Таблицы. Последние 40 записей передаются модели только при включённой галочке истории. Чаты и их контекст сохраняются в браузере с привязкой к аккаунту.

1. Выполни `supabase/update-8.sql` в SQL Editor проекта.
2. В Supabase → Edge Functions → Secrets задай `TOOKEN_API_KEY` и `ME_COACH_USER_ID` (UUID твоего пользователя из Authentication). Для чтения старого журнала доступной по ссылке Google Таблицы добавь `ME_TRAINING_SHEET_ID` (часть адреса после `/d/`). Для прямого подключения к OpenAI используется `OPENAI_API_KEY`. Ключи хранятся в секретах Supabase.
3. Из папки проекта выполни `supabase functions deploy me-coach --project-ref <project-ref> --no-verify-jwt`. Функция сама проверяет сессию через Supabase Auth и сверяет UUID пользователя с `ME_COACH_USER_ID`.

Необязательный секрет `ME_CHAT_PROFILE` задаёт контекст по умолчанию для новых чатов.

Затем открой `/me/#/coach` и отправь сообщение. Данные для тестов и английского используют прежние таблицы из `update-6.sql` и `update-7.sql`.
